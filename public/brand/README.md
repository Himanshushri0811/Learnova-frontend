# Learnova Brand Assets

This directory contains the official branding assets for Learnova.

## Expected Files

1. **`learnova-wordmark.svg`**: Full horizontal wordmark including the Learnova logomark, the brand name "Learnova", and the tagline *"A New Way to Learn."* Used in public navbar, headers, and footer.
2. **`learnova-mark.svg`**: Compact geometric icon / mark (graduation cap / star burst / open book abstraction in Navy `#0B1F4D`, Primary Blue `#2563EB`, and Cyan `#06B6D4` with Gold accent `#F59E0B`). Used in dashboards, mobile headers, and favicon.
3. **`learnova-watermark.svg`**: Low-opacity watermark variant designed for subtle accent placement without reducing text contrast or readability.

## Brand Palette Reference
- Light Surface: `#F8FAFC`
- Deep Navy: `#0B1F4D`
- Primary Blue: `#2563EB`
- Cyan Accent: `#06B6D4`
- Achievement Gold: `#F59E0B`
- Body Text: `#334155`

If official vector files are provided by the design team, place the approved files here with matching filenames to seamlessly replace the SVGs.
